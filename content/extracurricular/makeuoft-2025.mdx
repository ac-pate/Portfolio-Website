## Overview

Back at MakeUofT for round two. This time, we built something more ambitious: a wearable navigation system for visually impaired users that combines depth sensing, object detection, and haptic feedback.

## What We Built: Haptic Navigation Wearable

A hat-based wearable that helps visually impaired users locate objects through touch:

### How It Works

1. **Voice command**: User says "find me a red apple"
2. **Speech recognition**: OpenAI Whisper converts speech to text
3. **Semantic search**: YOLO v12 World model searches for the object in real-time
4. **Depth sensing**: Intel RealSense determines object distance and position
5. **Haptic feedback**: Motors on left/right sides of the hat vibrate to guide the user

### The Guidance System

- **Left motor vibrates stronger** → Turn left
- **Right motor vibrates stronger** → Turn right
- **Both motors intensify** → Getting closer to target
- **Vibration peaks** → Object reached

## Technical Stack

| Component | Technology |
|-----------|------------|
| Vision | Intel RealSense D400 (RGB + Depth) |
| Compute | Jetson Nano |
| Detection | YOLO v12 World (runtime-configurable targets) |
| Speech | OpenAI Whisper |
| Actuation | Arduino Nano controlling DC haptic motors |
| Integration | Custom pipeline connecting all subsystems |

## Architecture

```
[Voice] → [Whisper] → [Semantic Token]
                            ↓
[RealSense] → [YOLO World] → [Detection + Depth]
                            ↓
              [Haptic Controller] → [L/R Motors]
```

## Why YOLO World?

Traditional object detection requires pre-training for specific objects. YOLO World accepts text prompts at runtime — meaning users can search for *anything* describable in words, not just a fixed set of classes.

## 24-Hour Build

In one overnight session:
- Integrated four separate AI/ML systems (vision, depth, speech, detection)
- Built custom haptic feedback hardware
- Created a wearable form factor
- Demonstrated working end-to-end prototype
