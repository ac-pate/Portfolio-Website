## Overview

COEN 432 project: predict RNA secondary structure by determining which nucleotides form base pairs. Framed as binary classification predicting a 128×128 contact map.

**Result: Highest F1 score in class — 0.75 (single model), 0.768 (ensemble of 6 models).**

Beat all PhD and Master's students in this grad class as an undergraduate — and not by a small margin.

## The Challenge
Given an RNA sequence (a string of A, U, G, C nucleotides), predict its 3D folding pattern. Specifically: output a contact map showing which bases pair with each other.

Three critical problems:
1. **Long-range Dependencies**: Base pairs span 100+ positions. Baseline CNN receptive field (~7×7) insufficient.
2. **Class Imbalance (187:1)**: Only ~0.5% of position pairs form bonds.
3. **Tensor Alignment**: U-Net skip connections require matching dimensions. Solved with MAX_LEN=128 (power of 2).

## Architecture Evolution

Systematic progression from baseline to final solution:

| Model | Params | F1 | Innovation |
|-------|--------|----|-----------| 
| BaselineCNN | 40K | 0.36 | Insufficient receptive field |
| DilatedCNN | 77K | 0.53 | Dilated convolutions expand receptive field |
| U-Net | 7.8M | 0.67 | Encoder-decoder with skip connections |
| DeepResUNet | 15.2M | 0.74 | Residual blocks enable 25+ layers |
| DeepResUNetSE | 15.3M | 0.75 | SE attention blocks (+0.6% params) |

## Final Architecture: HybridRNA

**HybridRNA** (~17M params) combines DeepResUNetSE (CNN path) and TransformerRNA (attention path) with learned attention fusion. CNNs excel at local/multi-scale patterns; Transformers excel at long-range dependencies. Fusion layer learns per-position attention weights, enabling adaptive combination during training. F1: 0.75 (matches DeepResUNetSE, captures complementary patterns for ensemble).

## Key Findings

- **Pos-weight**: Lower values (1.0-2.0) outperformed higher (5.0) despite 187:1 imbalance. Optimal: pos_weight=1.0.
- **Batch size**: Smaller batches (16) outperformed larger (64) by 2.8% F1.
- **Ensemble**: 6 models averaged to F1=0.768 on Kaggle test set.

## Technical Details

- **Framework**: PyTorch with FP16 mixed precision
- **Training**: 200 epochs, batch size 16
- **Loss**: BCEWithLogitsLoss with pos_weight tuning
- **Architecture**: U-Net encoder-decoder, residual connections, dilated convolutions {1,2,4,8}, SE attention blocks
